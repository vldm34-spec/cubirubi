# Кубик Рубика — cubirubi 2.0

Переиздание сайта cubirubi.narod.ru: интерактивный куб + исследование «Число Бога».

## Что внутри

| Папка | Назначение |
|---|---|
| `src/core/` | Модель куба (`Uint8Array(54)`), ходы как перестановки, парсер трёх нотаций, узоры, IDDFS-перебор. Без DOM. |
| `src/render/` | three.js: 26 кубиков, 54 стикера, анимация слоёв, перетаскивание слоя мышью/пальцем, шлейф. |
| `src/workers/` | Web Worker перебора и Worker решателя Кочембы (пакет `cubejs`). |
| `src/ui/` | SVG-графики без библиотек, «музыка сфер» на Web Audio. |
| `src/essay.json` | Авторский текст «Число Бога», извлечённый из старого `index.html`. |
| `public/img/` | 37 графиков автора (`ris*.gif`, `tab*.gif`). |
| `public/data/` | Таблицы автора (`brack`, `cubi`, `serii`), переведённые из `.xls` в JSON. |
| `test/` | 16 тестов: инварианты группы, направление ходов, нотация, все 27 узоров, перебор, совместимость с Кочембой. |

## Запуск локально

```bash
npm ci          # зависимости
npm test        # тесты
npm run dev     # http://localhost:5173
npm run build   # сборка в dist/
```

## Размещение

Готовая сборка лежит в `dist/` — это статические файлы, никакого сервера не нужно.

**GitHub Pages (рекомендуется).** Залейте репозиторий на GitHub, в Settings → Pages выберите
Source: *GitHub Actions*. Файл `.github/workflows/deploy.yml` уже есть: при каждом push в `main`
прогоняются тесты, собирается `dist/` и публикуется. Адрес будет `https://<логин>.github.io/<репозиторий>/`.

**Любой хостинг.** Скопируйте содержимое `dist/` в корень сайта. Пути относительные (`base: './'`),
поэтому подпапка тоже подойдёт.

**Открыть с диска не выйдет** — Web Worker и `fetch` данных требуют http. Для локального
просмотра без сборки: `npx serve dist` или `python3 -m http.server -d dist 8080`.

## Что исправлено относительно оригинала

- Состояние куба больше не живёт в `<img src>`; перебор идёт ~100 000 ходов/с вместо 100.
- Перебор — IDDFS с отсечениями в отдельном потоке; счётчики без `Math.pow(10, i)`.
- Один парсер на три нотации узоров (`ппллвв`, `L2 R3 F1`, `D F2 U'`).
- Никаких `document.all`, `ActiveXObject`, `bgsound`, строковых `setTimeout`.
- Метрика перебора обозначена явно (QTM/HTM); в тексте эссе добавлено примечание про 20 vs 26.
- Новое: решатель Кочембы, лента ходов-скраббер, регулятор скорости, шлейф, живые графики по данным автора.
